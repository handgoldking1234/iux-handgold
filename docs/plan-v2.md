# 손금왕 v2 기획 — 양손 정밀 분석 + 사주명리 + 상담형 Q&A

## 1. 경쟁사 분석 (2026-11 조사)

| 구분 | 서비스 | 잘하는 것 | 약점 |
|---|---|---|---|
| 국내 사주 | 포스텔러 | 누적 860만 명, 자체 사주·점성술 분석, 운세 종류가 많음 | 손금 사진 분석 없음 |
| 국내 사주 | 점신 | 사주·신년운세·관상·타로, 전문가 1:1 채팅·전화 상담(유료) | 손금+사주 종합 없음, 상담은 비쌈 |

| 국내 유료 손금 앱 | 손금 진단 (₩4,400) | 사진 저장, 주요 선 분석 | 양손 결과가 같다는 리뷰, 오래된 UI |

**시장에서 비어 있는 자리:** 한국어로, 양손 손금 + 사주명리를 **한 사람의 상담처럼 하나로 엮어** 말해 주고, 이어서 질문까지 받아 주는 무료 서비스.

## 2. 손금왕 v2 차별점
1. **양손 비교:** 오른손·왼손을 따로 찍고 따로 분석. 주로 쓰는 손(지금·노력)과 덜 쓰는 손(타고난 것)의 차이를 짚어 "살면서 무엇을 키워 왔는지"를 말함.
2. **흑백 선 보정 + 잔선:** 사진을 흑백으로 바꾸고 선만 진하게 살린 "선 지도"를 보여 줌. 주요선은 실제 주름을 따라 가늘게 다시 따고, 잔선 정도(많음·보통·적음)도 판정.
3. **같은 사진 → 같은 결과:** AI 없이 규칙으로 계산 (해외 앱의 "찍을 때마다 다른 결과" 불만 해결). 사진은 밖으로 보내지 않음.
4. **사주명리:** 생년월일시(양력·음력·윤달), 성별로 사주팔자·오행·십성·신강/신약·대운·올해 세운 계산. 절기(입춘·절입)는 태양 황경으로 직접 계산, 진태양시 보정(서울 −32분) 선택.
5. **사주+손금 종합:** 두 체계가 같은 곳을 가리키는 것은 "확실한 강점", 엇갈리는 것은 "타고났지만 아직 덜 쓴 부분"으로 정리.
6. **상담형 Q&A:** "언제 결혼해요?", "이직해도 될까요?", "올해 돈은요?" 같은 질문에 손금·사주 근거를 함께 들어 전문가 말투로 답하고 읽어 줌. (말로 질문하기 지원 브라우저에서는 마이크 버튼)
7. **전문가 상담 흐름:** 인사 → 사주 원국 → 양손 → 종합 결론 → 올해 조언 → "궁금한 것 물어보세요". 선을 짚으며 말함.

## 3. 화면 흐름
1. 홈: 주로 쓰는 손, 궁금한 것
2. 사진: 상단 **[오른손] [왼손]** 탭 — 손마다 사진·정렬·분석·고치기가 따로 저장
3. 한 손 분석이 끝나면 "다른 손도 찍기" 안내
4. 결과 아래 **상담실**: 사주 입력 → 양손 비교 → 사주 원국 → 사주+손금 종합 → 질문하기
5. 무대 위 **흑백 선 보기** 버튼: 선 지도 + 다시 딴 주요선 + 잔선

## 4. 규칙 요약
- 손금 규칙: `docs/rules.md`
- 사주 계산: 연주 = 입춘(황경 315°) 기준, 월주 = 12절(315°+30°×k) 기준, 일주 = 율리우스일 기준 60갑자, 시주 = 2시간 단위(23시부터 다음 날 子시)
- 십성 = 일간과의 오행 생극·음양으로 판정 (지지는 정기 지장간 기준)
- 신강/신약 = 비겁·인성 비중(월지 가중 3, 일지 1.5, 나머지 1)
- 대운 = 양남음녀 순행 / 음남양녀 역행, 시작 나이 = 가까운 절기까지 날 수 ÷ 3
- 종합 = 6개 주제(리더십·창의표현·재물사업·조직안정·학습사고·관계애정)에 손금과 사주가 각각 점수를 주고, 둘 다 높은 주제를 결론으로

## 5. 빼는 것
**사망·수명 시기만 뺀다** (사용자 결정). 건강은 손금(생명선 선명도·건강선·잔선)과 사주 오행의 전통 '관리 포인트'로만 말하고, 진단하지 않으며 병원 안내를 붙인다.
