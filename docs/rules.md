## 1. 기본 원칙 ✅

1. **양손을 함께 본다.** 주로 쓰는 손은 지금의 나·사회 활동·노력의 결과, 덜 쓰는 손은 타고난 기질·속마음·가능성.
2. **좌뇌·우뇌:** 오른손잡이 기준 오른손은 논리·분석(좌뇌), 왼손은 감성·직관(우뇌). 왼손잡이는 반대.
3. **손금은 변한다.** 생활과 노력에 따라 선이 바뀐다 → 모든 풀이 끝에 "노력으로 바뀐다"는 말을 붙인다.
4. **상담 태도:** 겁주지 않고, 나쁜 표시는 "조심할 시기·준비할 점"으로 바꿔 말한다.
5. **풀이 순서(부록 사례 방식):** 손 정보 → 손 모양 → 주요 3선 → 세로 3선 → 특별한 표시 → 언덕 → 나이 흐름 → 정리·조언.

## 2. 손 모양 4유형 ✅(자동 추정 + 직접 고르기)

| 유형 | 손바닥 | 손가락 | 성향 | 손금 특징 |
|---|---|---|---|---|
| 땅의 손 | 네모 | 짧고 굵음 | 성실·현실·끈기·가족·자연 | 선 수가 적고 굵고 단순 |
| 물의 손 | 길쭉 | 길고 가늚 | 감수성·창의·예술·정신적 | 잔선 많음, 이중선·금성대·신비십자가 잘 나옴 |
| 불의 손 | 길쭉 | 짧음 | 열정·행동·모험·리더십·급함 | 선이 굵고 많음 |
| 공기의 손 | 네모 | 김 | 지적·분석·소통·호기심 | 선이 가늘고 선명, 두뇌선·감정선이 복잡 |

자동 추정: 잔선 밀도가 높으면 길쭉, 주요 3선이 깊으면 짧음.

## 3. 10개의 구(언덕) ✅

기본 50점 + 선 규칙 가점 + 사용자가 고른 "도톰한 언덕" +22 → 1위가 "OO구인".

| 구 | 위치 | 뜻 | 가점 규칙 |
|---|---|---|---|
| 목성구 | 검지 아래 | 명예·리더십·성취욕 | 감정선 검지 아래 +12 / 검지·중지 사이 +8, 독립형 두뇌선 +6, 솔로몬링 +15 |
| 토성구 | 중지 아래 | 책임·진지함·탐구 | 운명선 뚜렷 +12, 길게 +6, 감정선 중지 아래 +6 |
| 태양구 | 약지 아래 | 인기·예술·성공·재물 | 재물선 +18, 금성대 +5 |
| 수성구 | 새끼 아래 | 소통·사업·재치 | 사업선 +16, 두뇌선 곧음 +4 |
| 제1화성구 | 엄지와 생명선 시작 사이 | 용기·도전 | 생명선 선명 +8, 막쥔손금 +8 |
| 제2화성구 | 새끼 쪽 중간 | 인내·끈기 | 두뇌선 길고 곧음 +12, 막쥔손금 +6 |
| 화성평원 | 손바닥 중앙 | 균형 | 신비십자 +8 |
| 금성구 | 엄지 아래(생명선 안) | 애정·활력·가족 | 생명선 크게 휨 +15, 인복선 많음 +8 |
| 월구 | 손날 아래 | 상상·직관·창의 | 두뇌선 아래로 휨 +16, 운명선 월구 시작 +10 |
| 해왕성구 | 손목 위 중앙 | 직관·영감 | 신비십자 +8, 운명선 손목 중앙 시작 +6 |

엄지: 첫째 마디 행동력, 둘째 마디 사고력, 금성구가 힘의 원천 ⬜(사진으로 판단 어려움)

## 4. 기본삼대선

### 4-1. 생명선 ✅
| 특징 | 풀이 |
|---|---|
| 크게 휨(엄지 언덕을 넓게 감쌈) | 활력·사교성 |
| 완만 | 자기 페이스·꾸준함 |
| 길이 | 길이는 수명과 무관. 짧으면 몰입형 |
| 끊김 | 그 나이의 전환점(이사·이직) |
| 생명선 안쪽 영향선 | 가족·배우자 등 나에게 영향을 주는 사람 ⬜ |
| 생명선에서 위로 솟는 선 | 향상선(학업·시험), 개운선(노력의 결실) ✅개운선 / ⬜향상선 |
| 생명선에서 월구로 내려가는 선 | 여행선 — 멀리 이동·해외 생활 가능성 ⬜ |
| 이중 생명선 | 에너지가 강함 ⬜ |

### 4-2. 두뇌선 ✅
| 특징 | 풀이 |
|---|---|
| 곧음 | 현실·논리·계산 |
| 아래로 휨(월구형) | 상상·창작. 너무 깊이 내려가면 생각이 많아지니 생활 리듬 권유 |
| 제2화성구 쪽 | 사업 수완·실행 ⬜ |
| 길이 | 길면 신중·분석, 짧으면 직감·실행 |
| 생명선과 붙어 시작 | 신중 |
| 떨어져 시작(독립형) | 독립심, 성과형 일, 목성구 쪽으로 오르면 리더십·명예욕 |
| 이중두뇌선 | 두 가지 재능·병행. 한 가닥이 다른 가닥을 대신하는 "대체형"은 장점이 약함 |
| 삼중두뇌선 | 여러 재능 ⬜ |
| S자 커브 | 기획력 ⬜ |

### 4-3. 감정선 ✅
| 특징 | 풀이 |
|---|---|
| 중지 아래에서 멈춤 | 실속형, 마음을 쉽게 열지 않음 |
| 검지·중지 사이 | 균형 잡힌 애정 |
| 검지 아래(목성구까지) | 기준이 높고 헌신적, 소유욕·질투도 강할 수 있음 |
| 손끝까지 길게 | 정이 깊음, 인간관계 고민이 많음 |
| 많이 휜 곡선 | 연애를 중시 |
| 직선 | 표현보다 행동 |
| 아래로 처짐(하향) | 인간관계에서 상처받기 쉬움 → 기준을 세우라는 조언 ⬜ |
| 이중감정선 | 정이 깊고 감정의 결이 복잡, 갈등 때 갑자기 냉정해질 수 있음 |
| 직선 감정선 + 직선 두뇌선 | 자기주장이 강해 독불장군이 되기 쉬움 ⬜ |

### 4-4. 막쥔손금 ✅
- 감정선과 두뇌선이 한 줄. 강한 집중·추진력, 사업가 기질.
- 아류(한쪽만 이어짐), 파리형 등 변형이 있음 ⬜
- 막쥔손금이 있으면 하향 감정선 같은 다른 해석보다 막쥔손금 해석을 우선.
- 운명선이 막쥔손금을 넘어 위로 오르면 귀하게 봄 ⬜

## 5. 세로삼대선

### 5-1. 운명선 ✅
| 특징 | 풀이 |
|---|---|
| 손목 중앙에서 시작 | 자수성가 |
| 생명선 안쪽(금성구)·생명선 하단에서 | 가족·가까운 사람의 도움 |
| 월구에서 | 대중의 지지·인기 |
| 길게 중지까지 | 한 분야에서 오래 버팀. 너무 강하면 "팔자 센 운명선" — 일에 매여 가정을 소홀히 하기 쉬움 ⬜ |
| 감정선을 넘어 목성구로 휨 | 지도자 자질·존경받는 일 ⬜ |
| 감정선에 막힘 | 아직 자기 사업보다 조직이 맞음 ⬜ |
| 중간에 끊김 | 그 나이에 일의 방향 전환 ✅ |
| 두세 가닥 | 동시에 여러 일 ⬜ |
| 희미·없음 | 정해진 틀보다 스스로 길을 만듦 |

### 5-2. 재물선(태양선) ✅
- 약지 아래 태양구로 오르면 인기·이름값이 재물로 이어짐.
- 여러 가닥이면 재테크 기회 ⬜
- 제2화성구에서 오르는 태양선 = 귀인선: 주변의 도움·단골·인기 ⬜
- 장애선이 재물선을 끊으면 "무리한 욕심을 줄이고 저축할 때" ⬜
- 나이가 들며 길고 선명해질 수 있음(성공에 따라 변함).

### 5-3. 사업선 ✅
- 새끼손가락(수성구) 쪽으로 오름: 말·거래·상업 감각.
- 여러 가닥: 사업 재능이 다양 ⬜
- 두뇌선에서 출발해 새끼 쪽으로 가면 횡재선으로도 봄 ⬜

### 5-4. 자수성가선 ⬜
- 생명선에서 출발해 위로 오르는 운명선 계열. 전문 자격·기술로 자리 잡는 흐름.

## 7. 유년법(선 위치 → 나이) ✅(대략값)

- 생명선: 검지 아래 시작 10세 → 손목 쪽 80세. 손 크기가 달라 원래는 각도로 잰다.
- 두뇌선: 시작 20세 → 30·40·50세로 이어짐 ⬜
- 운명선: 손목 20세 → 두뇌선 교차 약 35세 → 감정선 교차 약 55세. 감정선 표준 위치를 벗어나면 보정.
- 사업선·재물선: 운명선 유년법을 그대로 적용.
- 여러 선(생명선·운명선·두뇌선)을 서로 맞춰 보며 정확도를 높이고, 결혼·이직 같은 실제 사건 나이로 기준점을 잡는다.
