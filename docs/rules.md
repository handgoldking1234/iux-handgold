# 손금왕 해석 규칙표

사용자가 촬영해 준 《손금 해석의 정석》 본문(손 유형, 구, 주로 쓰는 손, 선 명칭, 운명선·재물선·사업선)과
부록 실전 사례(막쥔손금, 이중두뇌선·이중감정선, 독립형 두뇌선, 금성대, 신비십자, 솔로몬링, 인복선, 개운선, 유년법)의
해석 체계를 바탕으로 **새로 쓴 문장**의 규칙표입니다. 책 문장을 옮기지 않았고, 건강·수명 판단은 넣지 않았습니다.

## 1. 주로 쓰는 손
| 찍은 손 | 해석 틀 |
|---|---|
| 주로 쓰는 손 | 지금의 나, 사회 활동, 노력으로 바꿔 온 모습 |
| 덜 쓰는 손 | 타고난 기질, 속마음, 앞으로의 가능성 (양손 비교 권유) |
| 오른손(오른손잡이 기준) | 좌뇌: 논리·분석 · 왼손잡이는 반대로 봄 |

## 2. 손 모양 4유형 (손바닥 × 손가락)
| 손바닥 | 손가락 | 유형 | 핵심 |
|---|---|---|---|
| 네모 | 짧음 | 🌳 땅의 손 | 성실·현실·끈기·가족, 선이 굵고 단순 |
| 길쭉 | 김 | 💧 물의 손 | 감수성·창의·예술, 잔선 많음 |
| 길쭉 | 짧음 | 🔥 불의 손 | 열정·행동·모험·리더십 |
| 네모 | 김 | 🌬 공기의 손 | 지적·분석·소통·호기심 |

자동 추정: 잔선 밀도가 높으면 길쭉, 주요 3선이 깊으면 짧음 (사용자가 직접 고칠 수 있음).

## 3. 10개의 구(언덕)
기본 50점 + 선 규칙 + 사용자가 고른 "도톰한 언덕" +22점 → 1위가 "OO구인".
| 구 | 위치 | 의미 | 가점 규칙 |
|---|---|---|---|
| 목성구 | 검지 아래 | 리더십·명예 | 감정선 검지 아래 +12 / 검지·중지 사이 +8, 독립형 두뇌선 +6, 솔로몬링 +15 |
| 토성구 | 중지 아래 | 책임·탐구 | 운명선 뚜렷 +12, 길게 +6, 감정선 중지 아래 +6 |
| 태양구 | 약지 아래 | 인기·예술·성공 | 재물선 +18, 금성대 +5 |
| 수성구 | 새끼 아래 | 소통·사업 | 사업선 +16, 두뇌선 곧음 +4 |
| 제1화성구 | 엄지·검지 사이 | 용기·도전 | 생명선 선명 +8, 막쥔손금 +8 |
| 제2화성구 | 새끼 쪽 중간 | 인내·끈기 | 두뇌선 길고 곧음 +12, 막쥔손금 +6 |
| 화성평원 | 손바닥 중앙 | 균형 | 신비십자 +8 |
| 금성구 | 엄지 아래 | 애정·활력·가족 | 생명선 크게 휨 +15, 인복선 많음 +8 |
| 월구 | 손날 아래 | 상상·직관·창의 | 두뇌선 아래로 휨 +16, 운명선 월구 시작 +10 |
| 해왕성구 | 손목 위 중앙 | 직관·영감 | 신비십자 +8, 운명선 손목 중앙 시작 +6 |

## 4. 선 · 특수 표시
- 운명선 시작점: 손목 중앙(자수성가) / 생명선 안쪽·금성구(가족·가까운 사람의 도움) / 월구(대중의 지지·인기)
- 재물선(약지 쪽): 인기·이름값이 재물로 / 사업선(새끼 쪽): 거래·장사 감각
- 독립형 두뇌선(생명선과 떨어져 시작): 독립심, 성과형 일
- 막쥔손금: 강한 집중과 추진, 쉬는 법 필요
- 이중두뇌선: 두 가지 재능·병행 / 이중감정선: 깊은 정, 감정 표현 권유
- 금성대: 예술 감각, 감정 기복 관리 / 신비십자: 직감·영감 / 솔로몬링: 사람 보는 눈·리더 / 인복선: 주변의 도움
- 개운선(생명선에서 위로): 그 나이 즈음 노력의 결실

## 5. 유년법 (선 위치 → 나이, 대략값)
- 생명선: 시작(검지 아래) 10세 → 끝 80세, 길이 비례
- 운명선: 손목 20세 → 두뇌선 교차 35세 → 감정선 교차 55세
- 끊긴 지점·개운선 지점·운명선 시작점을 나이로 바꿔 "📅 나이로 보는 흐름"에 표시

## 6. 말하는 원칙 (책의 상담 태도)
겁주지 않고 긍정적으로, 선은 노력으로 바뀐다는 점을 마지막에 덧붙임.
