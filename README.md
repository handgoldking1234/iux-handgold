# Handgold — 손금왕

손바닥 사진을 가이드에 맞추면, **AI 없이 기기 안에서** 손금선을 찾아 풀이하고 말로 읽어주는 웹앱 (단일 HTML).

## 동작 방식
1. 사진(촬영·앨범·Ctrl+V·드래그) 또는 카메라로 손을 점선 가이드에 맞춤
2. 영상 처리로 어두운 가는 선(손금)을 강조한 지도를 만들고, 생명선·두뇌선·감정선·운명선·태양선·막쥔손금 후보 모양과 맞춰 가장 잘 맞는 선을 고름
3. 선의 길이·모양·끝나는 곳·선명도·끊김을 해석표(규칙)에 대입해 풀이·점수·유형 생성
4. 선을 하나씩 짚으며 음성으로 풀이 (휴대폰 기본 음성 또는 Azure 무료 자연 음성)
5. 잘못 잡힌 선은 '직접 고치기'에서 눌러 수정 → 풀이가 바로 다시 써짐

- 사진은 서버로 보내지 않음, API 비용 0원
- 같은 손금이면 항상 같은 풀이

## 배포 (Vercel)
- 저장소 연결 후 그대로 Deploy (빌드 설정 없음)
- 선택: 자연 음성을 쓰려면 환경변수 `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`(koreacentral) 추가 후 Redeploy

## 구조
- `index.html` — 앱 전체 (분석·해석표·음성 포함)
- `api/tts.js` — Azure 음성 서버 함수 (선택)

> 손금 풀이는 재미로 보는 오락 콘텐츠입니다. 건강·수명은 판단하지 않습니다.

## 해석 규칙
《손금 해석의 정석》의 해석 체계(손 4유형, 10개 구, 주로 쓰는 손, 운명선 시작점, 재물선·사업선, 특수 문양, 유년법)를 바탕으로 새로 쓴 규칙표: [docs/rules.md](docs/rules.md)
